## 关于 / About

想用的东西要是没有，或者做得不够好，就自己写一个。

做东西有三条原则 ——

- **本地优先** — 数据放在你自己的硬盘上，不是我的服务器上。
- **零订阅** — 买断或者免费，不接受按月交租。
- **够用就好** — 不堆功能，不为了好看牺牲启动速度。
